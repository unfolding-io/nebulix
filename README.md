# Nebulix

Astro theme (blog, portfolio, restaurant menu) with Sveltia CMS.

The application lives in **[`SITES/AstroThemes`](SITES/AstroThemes/)**.

```bash
cd SITES/AstroThemes
cp env.txt .env   # fill in values
npm install
npm run dev
```

See [`SITES/AstroThemes/README.md`](SITES/AstroThemes/README.md) for full documentation.
